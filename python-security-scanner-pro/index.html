Python Security Scanner Pro

Privacy Policy · Effective 12 November 2026 · Version 1.0.0
Microsoft Store product: 9PCRSVQPWSFW

Your project stays local. Code and secret checks run on your device. Online dependency checks are optional and send exact package names and versions to PyPI after your confirmation. This release has no telemetry, cloud sync or AI service.

1. Information the application processes

When you choose a local folder, the application reads eligible project files to analyze Python code and detect possible secrets. It records project names and paths, scan scope and settings, timestamps, file hashes, an available Git revision, engine versions, coverage issues, redacted findings, review statuses and reasons you enter. It does not import or execute your project, run setup scripts or tests, install project dependencies, or execute a selected environment's Python interpreter.

Optional dependency input is read from supported exact requirements entries or distribution METADATA files in a selected Windows environment. The information includes package names and exact versions. Unsupported and unreadable inputs are reported as incomplete coverage. Git history is not scanned in this release.

2. Local storage and temporary processing

The default workspace is %LOCALAPPDATA%\PythonSecurityScannerPro. Store package redirection may change its physical location; use Settings → Open Data Folder to locate the active workspace. A custom workspace may be specified through launch configuration. Project records, history, settings and decisions are stored in a local SQLite database. A local lock file prevents simultaneous use of one workspace.

During a scan, a bounded copy of eligible source files and temporary engine output are written to a temporary subfolder in the workspace. These temporary files can contain original source and secrets while the engines analyze them. They are removed when a scan finishes or is canceled. A crash or power failure can leave temporary files; with the application closed, you can delete the contents of this application's temporary folder. Do not delete unrelated folders.

Persistent finding evidence hides detected secret values. Python previews conservatively hide string literals and comments, and common sensitive patterns in descriptions and review notes are masked. Redaction is not a guarantee that every possible sensitive value in filenames or free-form notes will be recognized. Do not include secrets in review notes. Local database files, temporary files, samples and exports are not encrypted by this application; protection depends on your Windows account, permissions and device encryption.

3. Optional online dependency checks

Local code and secret checks work without an internet connection. If you enable dependency checking, the application identifies the selected requirements file or environment and asks for confirmation before each online scan. It sends exact package names and versions in HTTPS requests to pypi.org using the bundled pip-audit vulnerability service. PyPI and network providers may observe your IP address, requested package metadata, time and standard connection information. Your source files, local database and review notes are not uploaded as part of these requests.

Requests use TLS certificate verification. A temporary per-scan response cache is removed with the scan's temporary files. This release does not reuse a persistent offline vulnerability database. If lookup fails, local checks can still finish and dependency coverage is marked incomplete. PyPI is operated by the Python Software Foundation; see its Privacy Notice.

4. Telemetry, AI and third parties

This release includes no application telemetry, advertising SDK, cloud synchronization, remote AI service, API-key storage or publisher-hosted backend. Bundled Bandit and Gitleaks engines run locally; pip-audit contacts PyPI only for an authorized dependency lookup. The publisher does not automatically receive your projects, findings, reports or diagnostic data. The app does not keep a persistent scan-content log; transient engine diagnostics remain in the per-scan temporary folder.

Microsoft separately processes Store purchase, installation, update, licensing and Windows diagnostic information under the Microsoft Privacy Statement. This public policy is hosted on GitHub Pages. Visiting it sends ordinary web requests to GitHub under the GitHub General Privacy Statement. This page has no publisher-added tracking, external fonts or analytics.

5. Reports, editors and sharing

Reports in HTML, PDF, CSV, JSON or SARIF are saved to a location you choose. They include scope, findings, review decisions and limitations and can contain project paths or other confidential metadata. Review them before sharing. If you select a shared or synchronized folder, other services may copy those files according to their own settings. The app does not automatically email or upload reports.

Open in Editor opens the selected original file in Windows Notepad. The original may contain unredacted secrets. The application's redacted preview does not modify your original files. External documentation, privacy and support links open your browser or email application only when selected.

6. Retention and deletion

History remains until you remove it. Projects → Remove Project & History deletes the selected project's database records and associated scan decisions. Settings → Delete All Local History & Settings clears workspace records and preferences after confirmation. Source files, exported reports and the copied Sample Project are not deleted by these controls. Remove those files separately wherever you saved them.

To remove the complete workspace, locate it in Settings, close the application and delete that specific folder. Uninstall behavior depends on installation type and Windows storage handling; custom workspaces and exports may remain. Ordinary database or file deletion is not secure erasure and does not remove separate backups or synchronized copies. The publisher cannot remotely retrieve or delete data that stays on your device.

7. Permissions and contact

The application runs under your Windows user account and does not need administrator rights for normal scans. It needs access to the folders and report locations you select and network access for authorized dependency lookups. The MSIX full-trust desktop capability does not mean the app runs as administrator. It does not request camera, microphone, contacts or location access.

For support or privacy requests, contact Aria Vision at sn.moosavi@gmail.com with “Python Security Scanner Pro” in the subject. Do not send credentials or unnecessary source code. Email discloses your address and message to the publisher and the email services involved. Contact the publisher about information you separately provide in correspondence and applicable privacy rights.

8. Updates

Changes will be published here with an updated effective date. The application includes the policy for its shipped version. Material changes to its data practices will also be described in release notes or an appropriate application notice. The app does not automatically download policy updates.
